Purpose and users

The app is for the operator's personal use only. It connects the operator's own Gmail accounts to the AI assistant Claude (Anthropic) so he can search his own email. It is not offered to other users.

Data accessed

With the account holder's consent, the app requests read-only access to Gmail (scope gmail.readonly) plus basic profile information (email address). It does not send, delete or modify email.

How data is used

Email content is retrieved only when the account holder asks Claude a question, and is passed to Claude to answer that question. Data is not sold, not used for advertising, and not shared with any other third party.

Storage

OAuth tokens are stored in a private Google Cloud project of the operator (EU region). Email content is not stored by the app.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
